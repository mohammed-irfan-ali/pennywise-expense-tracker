# PennyWise – Personal Expense Tracker

**Final Web Development Project | InternNova Internship**  
**Student:** Mohammed Irfan Ali

## Project overview
PennyWise is a responsive personal finance website that helps users record income and expenses, view their balance, and understand spending by category. It is built using HTML, CSS and vanilla JavaScript.

## Features
- Add income and expense transactions.
- Edit and delete existing transactions.
- Automatically calculate total income, expenses, balance and transaction count.
- Search transactions by description.
- Filter by transaction type and category.
- View a category-wise spending chart.
- Save entries in browser `localStorage`.
- Responsive layout for desktop, tablet and mobile screens.
- Mobile navigation menu and form validation.

## Technologies and concepts
HTML5 semantic structure, CSS3, Flexbox, CSS Grid, media queries, JavaScript variables, functions, arrays, objects, conditions, array methods, DOM manipulation, events and localStorage.

## Run locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or open it directly in a browser.
4. Add sample income and expense entries to test the dashboard.

## GitHub Pages
After pushing the project to a public GitHub repository:
1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish and copy the live website URL.

## Important notes
- Data is stored in the current browser profile only. It is not synced to another device.
- Replace the repository and live website placeholders in `PROJECT_REPORT.md` after publishing.
- Capture real screenshots of the running website and place them in `screenshots/` before final submission.
